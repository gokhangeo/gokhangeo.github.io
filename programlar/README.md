# Programlar

Bu klasöre yüklediğiniz her dosya, **TKGM Uygulamalar** sayfasındaki
"Programlar" bölümünde otomatik olarak listelenir ve indirilebilir.

https://gokhangeo.github.io/gokhan/uygulamalar/

## Dosya yüklemek
1. GitHub'da bu klasörü açın: https://github.com/gokhangeo/gokhan/tree/main/programlar
2. **Add file → Upload files** ile dosyayı sürükleyin, **Commit changes** deyin.
3. 1–2 dakika içinde sayfada görünür.

Silmek için dosyayı açıp çöp kutusu simgesine basın.

Not: GitHub web arayüzünden en fazla **25 MB**, git ile en fazla **100 MB** dosya yüklenebilir.
Bu dosya (README.md) listede gösterilmez.
